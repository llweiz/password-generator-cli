# password-generator-cli
本地密码生成与账号备注管理工具，随机生成高强度密码，内置密码强度检测，本地保存账号备忘信息。
开源协议：MIT

## 功能清单
1. 自定义长度生成随机密码
2. 自由开关大写字母、数字、特殊符号
3. 密码强度分级检测（弱/中/强/很强）
4. 本地保存账号、密码、备注信息
5. 查询全部账号记录、删除指定账号

## 安全提示
仅用于本地日常轻量使用，不建议存储金融、核心业务高敏感密码；项目无加密存储，请勿将包含真实密码的文件上传公开仓库。

## 数据存储
账号信息保存在 password_store.json，文件首次运行自动创建。
